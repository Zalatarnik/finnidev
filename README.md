# Мобильная игра «Питомец Финни»

## Назначение продукта

«Питомец Финни» - это мобильная игра, сочетающиая элементы визуальной новеллы и экономического симулятора. Главная цель продукта - обучение базовой финансовой грамотности через игровой процесс. Игрок взаимодействует с инопланетным питомцем, получает карманные деньги и учится грамотно распределять бюджет, расставляя приоритеты между обязательными тратами (еда, здоровье) и необязательными (игрушки, настроение).

---------------------

## Технологический стек

* Игровой движок: Unity 6.6 (6000.6.2f1) / рекомендуется версия не ниже 2022.3 LTS.
* Язык программирования: C#.
* Платформа сборки: Android (Android SDK, OpenJDK, NDK).
* UI: Unity UI + TextMeshPro (адаптивная верстка от 360 dp).
* Управление: Unity Event Systems (нативный Drag & Drop, виртуальный джойстик).

---------------------

## Состав репозитория

Корневая папка проекта finnidev имеет стандартную структуру проекта Unity и включает в себя:
* 📁 Assets/ - основная папка с ресурсами игры (скрипты, графика, префабы и сцены).
* 📄 FinniGame.apk - уже собранный установочный файл игры для Android (находится внутри папки Assets согласно структуре).
* 📁 Packages/ - кэш и настройки установленных пакетов (Package Manager).
* 📁 ProjectSettings/ - глобальные настройки проекта Unity (Input, Player Settings, Physics и др.).

---------------------

## Иерархия сцен (Архитектура в папке Assets/Scenes)

* **InitScene** - Менеджер инициализации. Техническая точка входа в игру. Создает глобальные бессмертные системы (в т.ч. GLOBAL_SYSTEMS и MoneyCanvas - сквозной кошелек игры).
* **SampleScene** - Главный Мир и Сюжет. Отвечает за линейное повествование (комиксы, диалоги), кастомизацию пришельца и свободное перемещение.
* **MoneyDistributionScene** - Мини-игра «Распределение бюджета». Изолированная локация для физического планирования ресурсов на столе.
* **SupermarketScene** - Экономическая локация. Симуляция покупок с разделением товаров по полкам (Еда, Уход, Игрушки) и механикой оплаты на кассе.

## Быстрый запуск

### Требования к окружению

* Установленная среда Unity (версия 2022.3 LTS или выше, целевая - 6000.6.2f1).
* Установленные модули в Unity Hub: Android Build Support, OpenJDK и Android SDK & NDK Tools.

### Запуск проекта в редакторе Unity

* Склонируйте или распакуйте репозиторий с проектом на ваш ПК.
* Откройте Unity Hub, нажмите кнопку Add (Добавить) и выберите корневую папку проекта (finnidev).
* Дождитесь импорта ассетов и откройте проект в редакторе.
* В окне Project перейдите по пути Assets/Scenes и дважды кликните по сцене InitScene.
* Нажмите кнопку Play (▶) в верхней части редактора.
⚠️ **ВАЖНО:** Для корректной инициализации бессмертного кошелька и глобальных систем, запуск игры в редакторе всегда должен осуществляться строго со сцены InitScene.

### Сборка релизного APK-файла (Android)

* В верхнем меню Unity выберите File -> Build Settings.
* Убедитесь, что платформа переключена на Android и все 4 сцены добавлены в Scenes In Build (сцена InitScene должна быть под индексом 0).
* Нажмите кнопку Build.
* Укажите папку для сохранения и имя файла.
* По завершении сборки перенесите полученный APK-файл на физическое Android-устройство и установите его.
